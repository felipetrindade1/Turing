## Turing - Transformando o Futuro da Tecnologia
### 📅 Data de Criação:
Janeiro de 2025

### 💻 Sobre o Projeto:
Este site foi desenvolvido para apresentar a Turing, uma empresa global de tecnologia que conecta empresas a desenvolvedores de software altamente qualificados. O site tem como objetivo fornecer informações sobre os serviços oferecidos, cultura da empresa, projetos e oportunidades de carreira.

### 🛠 Tecnologias Utilizadas:
HTML5
CSS3
JavaScript
🌐 Funcionalidades do Site:
Página Inicial: Apresentação da Turing, com informações sobre sua missão e visão.
Serviços: Descrição detalhada dos serviços oferecidos pela empresa, como soluções de software personalizadas.
Cultura: Seção dedicada à cultura e aos valores da Turing, destacando o ambiente de trabalho.
Carreiras: Página com oportunidades de emprego e benefícios para os funcionários.
Contato: Formulário simples para contato com a Turing, incluindo informações de localização e e-mail.
### 🚀 Funcionalidades Interativas:
Animações: Animações simples para transições de conteúdo e elementos visuais, para melhorar a experiência do usuário.
### 📈 Objetivos do Projeto:
Criar um site responsivo e interativo para promover a Turing.
Desenvolver uma interface limpa, fácil de navegar, com foco na usabilidade.
Demonstrar habilidades de design e desenvolvimento front-end.
